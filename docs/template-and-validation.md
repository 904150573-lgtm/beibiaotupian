# 模板适配与本机验收

## 使用现有模板

将之前的参数模版(3).psd 放到 `~/Desktop/背标模版.psd`，并安装模板字体。原 PSD 保持不变；每次任务从临时文件副本打开，为每个产品复制独立文档。缺字体时停止。

## 更换模板

1. 在 Photoshop 打开新 PSD，确认可编辑文本图层，当前引擎正文换行要求点文本。
2. 运行 `scripts/inspect_template.jsx`，将 JSON 保存到 `config/template-map.json`。
3. 更新 `config.json` 的尺寸、文件大小（可设为 0 关闭大小检查）、字体列表与路径。
4. 按新图层 ID 更新 `layout.rows` 和 `layout.nutrition`。温馨提示使用 `duplicate: true` 从指定源图层复制，不复用已修改文字的样式。
5. 更新正文 x/y、可用宽度、底边和营养表四组定位参数。营养表 box 为 `[中心x, 顶边y, 最大宽度, 最大底边]`，单位是像素。
6. 先用短文本、再用最长配料/致敏文案做本机验收。不要仅通过放宽边界来忽略框线重叠。

样式从实际 PSD 读取，映射中的 `style_runs` 是旧模板参考信息，不是统一样式参数；不要将所有 tracking 改为同一个值。

## 本机验收步骤

- 运行双口味示例，确认两款分别输出 JPG/PSD，正文无旧产品内容。
- 在生成的可编辑 PSD 中逐行检查 tracking、字号、leading、混合字符样式、字偶距模式与段落对齐。
- 核对数字单位及 `20.0克` 等显示精度，糖 NRV 留空。
- 删除示例产品类别，确认整行隐藏并出现报告提示。
- 加长配料或致敏提示，确认正常换行；超过区域时该款报告失败，不出现成功 JPG。
- 缺字体、改图层 ID/文字、换模板尺寸时，应停止并说明原因。
- 检查营养表列对齐、框线重叠、JPG 清晰度与 sRGB 颜色。
- 比对原模板文件，确认未被覆盖。

## 已知限制

字符按行号和 UTF-16 字符位置继承样式；中文常用字符及普通标点适用。含 Emoji 或复杂组合字符的标签需要单独适配。文字变化后手动 kerning 仍继承位置上的数值，新字符组合的视觉间距需检查。自动字偶距保持原模式，但字体按新字符组合计算的视觉效果可能变化。

一次 Excel 验证失败时不会生成新任务；已存在的旧任务不会被自动删除，请根据终端提示判断成功。Photoshop 逐产品处理，某款失败后继续下一款，详情见运行报告。PSD 先保存；JPG 转换失败时报告明确说明 PSD 已保存。
